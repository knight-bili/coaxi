# Coaxi Application Icon

The customer selected and approved this flat white-and-gold double-wing artwork on
2026-10-24 for Coaxi and authorized its use in the application and source repository.
The design was created with native image generation during the branding discussion.

`icon.png` is the unmodified approved 1254×1254 RGBA master, SHA-256 `f7280a699237a398199a59c5e66c534cfff0ccde93c23a51b93d0d6ae015eadd`.
`icon.ico` contains resized copies for Windows. `icon.svg` is an SVG container embedding
the same PNG; it is not a claim that the raster artwork has been redrawn as vector paths.
Desktop, Web and mobile assets derive from this master, without adding 3D effects.

Upstream runtime logos and other artwork retain their own license and provenance notices.
