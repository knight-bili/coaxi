coaxi delegation <command>

start --agent-type <runtime> --task <text> [--working-dir <absolute-path>]
status --task-id <id> [--task-id <id> ...] [--wait-ms <milliseconds>] [--after-cursor <cursor>]
cancel --task-id <id>
resume --task-id <id> [--reason <interruption-context>]
read --task-id <id> [--cursor <cursor>] [--limit-bytes <1..65536>]
history --task-id <id> [--before-cursor <cursor>] [--limit <1..100>]

Start, cancel and resume operate on Core-admitted delegation identities.
Status returns {tasks,cursor}; read and history return exact scoped pages.
Omit wait-ms for a snapshot; zero waits without timeout; positive values are capped at 60000 ms.
Do not infer failure from a timeout or disconnect. A blocked request requires the User.
Full operation descriptions and exact input/result schemas are available in each command's help.
