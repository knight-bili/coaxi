# Coaxi 品牌与兼容边界

当前产品名称统一为Coaxi。检查必须覆盖Desktop/Web、系统菜单与托盘、弹窗、通知、设置、渠道文案、本地化、产品链接与移动资源，而不是只检查启动页。

## 必须使用Coaxi

产品标题、退出/打开动作、默认功能标签、当前教程、产品拥有的通知、下载与仓库入口。界面不得显示“沿用某原版实现”之类研发过程说明；用户只需要操作本身及权限影响。

## 必须保留的兼容标识

- Windows安装appId、productId和已有数据根；SQLite文件及迁移历史。
- `window.rovai`桥、`rovai:` IPC、现有环境变量和旧资源/深链协议；新入口同时接受Coaxi协议。
- Rust crate/binary名、既有CLI命令、导入格式标识、对象ID、profile角色和已保存的受控头像引用。
- 上游版权、许可证、来源锁定、第三方产品名、冻结历史及用户自己的姓名、消息和文件正文。
- 已确认的模型输入合同、冻结Bootstrap与投递证据。不能为清除关键词重写历史或改变模型可见合同；新增语义变化按模型输入治理单独确认。

保留项应按其用途解释，不能用作普通界面的当前产品名。兼容项只有在制定独立迁移与恢复方案后才改动。

## 验证

先扫描Rovai/rovai/Codeg/codeg，按用户文案、兼容标识、上游来源与历史/用户数据逐项处理；重新检查多语言键值对应关系。测试关闭弹窗和托盘，核对程序及网站链接；打包后在独立数据根核对真实页面。安装升级前保存数据快照，验证原ID和消息保留；不在日常目录上启动第二个Core。
