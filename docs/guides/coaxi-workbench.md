# Coaxi 使用说明

Coaxi 把队员、会话、无限画布与工程放在同一个工作区。当前为 Windows 试用阶段，遇到问题时保留原数据并记录操作步骤。

## 启动与队员

从桌面 Coaxi 快捷方式启动。首次使用依次选择语言、队员和本机智能体。星璃负责需求调查和实现，月汐负责评审，铃音负责测试，绘羽负责设计；这些是默认分工，你可以自行修改。已有用过或自定义的队员资料不会被升级覆盖。

## 智能体和模型

Coaxi 使用你电脑上选择的那份智能体程序。Codex 桌面和独立 Codex CLI 可能是不同版本，返回的模型目录也可能不同。模型列表缺项时先刷新检测，并核对独立 CLI 版本；不要直接删除登录或数据目录。

2026-10-24 本机实测：独立 Codex CLI 0.154.0 返回四个普通模型，升级到官方稳定版0.164.0后返回七个，补齐gpt-6.1-sol、gpt-6-sol和gpt-6-luna。此结果仅是这台机器当时的观察，不作为其他账号的固定名单。

“默认”表示跟随智能体原生配置；目录里的推荐模型不一定等于用户保存的默认。显式选择时使用原生model值，推理参数以对应程序的实际目录为准。列表出现某模型不代表账号一定有使用权限，真实任务的结果由提供方返回。

## 工程与画布

打开或克隆工程后，在文件树中选择文件，查看或编辑正文；在Git工作区核对Diff、分支、提交和冲突。画布可以同时摆放会话、文件、终端、便笺和区域，卡片仍使用同一个Core中的真实对象。

## 关闭窗口

Windows关闭按钮可以选择退出或最小化到系统托盘。托盘模式下后台任务可以继续，退出会执行保存和清理。勾选记住后可在“设置 → 通用 → 窗口”调整。此次改动不改变启动时的窗口大小或最大化规则。

## 旧安装与数据

升级继续使用原安装身份和原数据根；Windows现有数据目录`%LOCALAPPDATA%/Codeg Rovai Workbench`的旧名称为兼容用途。不要手动改名、搬移或删除该目录。用户工作区、账号、模型配置、历史消息及自定义头像保留。

## 反馈问题

请提供出现问题的页面、操作顺序、预期和实际结果，必要时从诊断入口导出信息。不要在公开Issue中提交API密钥、登录凭据或未经检查的私有对话。
