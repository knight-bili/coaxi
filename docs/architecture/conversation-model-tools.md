# 会话模型工具

Rovai Core 是请求、问题、来源授权、Mission 与自动化的唯一业务权威。复用 Codeg 四项工具名、问题卡及资料选择方式，不引入另一个任务引擎或调度器。
字段、状态及版本轴由[会话模型工具 v1](../contracts/conversation-model-tools-v1.md)拥有；启动恢复由[Runtime Launch v61](../contracts/runtime-launch-and-verification-v61.md)拥有。

## 数据和调用

User 在原队员表单分配可选工具，在原公聊/私聊输入框选择旧讨论。Host 对已认证 User 注入编辑端身份，经领域命令保存策略、授权和答案。
接收 Run 从真实 User 正文选取明确的来源标记，冻结来源边界与策略；正文沿原 Context 装配，不增加新的提示词章节。
模型调用固定 stdio 服务；Core broker 核对绑定、执行代次与冻结目录后记录原请求意图。只读查资料不取得任何新授权，创建请求进入原 Mission/Automation 服务的同一事务。
问题等待真实 User，首份回答和 outbox 同事务写入。原 stdio 连接只领取一次，实际 flush 后记录交付事实。Host/连接中断时保留未知状态，不能另起调用补发。

来源有界投影只从已发布可见消息及对应原运行证据读取文字和工具名；统计来自实际收集的计数。私有原生 locator、导入路径、参数、结果正文和隐藏思考不进入投影。
原导入文件及 native Session 只作来源证明，不能成为 Core Conversation 身份。Private Scope 和明确来源授权分别核对，公开讨论不能继承私人材料。

## 兼容与所有权

原 Built-in 授权独立。可选字段 None 保留旧字节，历史 Run 保留原冻结。帮手新建真实子作用域后独立冻结，不复制父会话凭据或授权。
自动化所有权附表把动作和时区绑定原定义，以定义版本和附表修订共同核对并发编辑。唯一原调度器按 UTC 发生记录去重，生成 Mission 后等待 User 启动。
配置迁移只处理被明确选择的总开关，保留队员分配；原修订与导入前快照支撑精确撤销。不得因接收端同名成员而恢复来源机权限。
Desktop/Web 和两个原生客户端都复用原问题卡、成员设置与自动化工作区。资料加入原草稿，断线恢复只另存操作编号；没有第二份答案、草稿或授权权威。
